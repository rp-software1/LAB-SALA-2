1. ¿Qué aprendiste en cada fase?

Aprendí a crear componentes reutilizables con props, manejar datos con estado, usar efectos para cargar información, consumir APIs con Axios, navegar entre páginas con React Router, compartir información con Context y conectar toda la aplicación con un backend real para guardar y consultar datos.

2. ¿Qué parte del sistema te sorprendió más? ¿Qué cambiarías?

Lo que más me sorprendió fue ver cómo un pedido que se crea en el frontend llega al backend y se guarda en la base de datos, haciendo que toda la aplicación funcione de forma conectada. Si pudiera rediseñarlo, mejoraría el manejo de errores y agregaría más validaciones para evitar pedidos o acciones inválidas.
