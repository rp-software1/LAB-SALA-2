# 📝 Reflexión - Día 9

## Lo que aprendí

Durante este día aprendí cómo conectar una aplicación de React con una API utilizando Axios. También entendí mejor la diferencia entre trabajar con datos mock y preparar la aplicación para consumir información de un backend real.

---

## Lo que más me llamó la atención

Lo que más me gustó fue ver cómo todas las páginas trabajan juntas mediante Context API. Al seleccionar una mesa, agregar platos y enviar la comanda, toda la información se comparte automáticamente sin tener que pasar datos entre componentes.

---

## Dificultades que tuve

Al principio me confundí con la organización del proyecto y con las funciones que debía modificar. También tuve algunas dudas sobre cuándo usar datos mock y cuándo llamar a la API, pero revisando el código y haciendo pruebas pude entender mejor el flujo.

---

## Cómo resolví los problemas

Fui revisando cada archivo paso a paso, comparando el funcionamiento con el de otros componentes como `MenuPage` y `MesasPage`. Además, probé varias veces la aplicación para verificar que el pedido, la mesa seleccionada y el carrito funcionaran correctamente.

---

## Lo que considero más importante

Creo que lo más importante fue aprender a organizar el proyecto separando los servicios de la interfaz y utilizando una sola instancia de Axios con interceptores. Esto hace que el código sea más limpio y fácil de mantener.

---

## Lo que debo seguir practicando

Quiero practicar más TypeScript para acostumbrarme al uso de tipos e interfaces. También me gustaría seguir trabajando con APIs reales y mejorar el manejo de errores y validaciones dentro de la aplicación.
